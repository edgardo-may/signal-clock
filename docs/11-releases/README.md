# 11 — Releases

**Estado:** IMPLEMENTADO (release evidence/history); module closure and ADR templates added.

Use [module closeout](module-closeout-template.md) and [ADR template](adr-template.md). Release records should state exact source commit, deployed artifacts, environment, evidence provenance, changes made, rollback point and whether production/data writes occurred. Do not treat “READY” or a source commit alone as proof of every component’s deployment.
