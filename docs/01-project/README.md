# 01 — Project

**Estado:** IMPLEMENTADO (documentación inicial).

Signum Clock is a multi-tenant attendance and workforce application. The repository contains the React/Vite frontend, Vercel Employee Function, separate integration/API packages, Attendance/Workday runtime components, SQL history/candidates, tests, and operational evidence. The physical ZKTeco ADMS gateway is maintained in a separate repository.

Start with [project status](../../PROJECT_STATUS.md) and [architecture](../../ARCHITECTURE.md). Treat dated reports as evidence snapshots, not current instructions.
